About

      
I'm a Python data engineer specialising in web scraping: from large-scale collection on protected, JavaScript-heavy sites to clean, standardised datasets delivered to databases, S3, CSV or CRMs. My long-running pipelines process 100k+ records per day at a 98% success rate.

      
I spent three years at GulzarSoft, progressing from Python Developer to Senior Software Engineer and Team Lead of 7+ engineers. Since then I have built 200+ production scrapers for a UK e-commerce brand, collected 3.3M court decisions for a legal-AI company, standardised Florida county property records into one schema, and delivered 7 live lead-generation dashboards.

      
I'm comfortable owning a system end to end (architecture, build, validation, documentation, handover) and equally comfortable inside a team: setting coding standards, reviewing code and mentoring.
